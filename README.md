## ⚡ Overview
ApexVector is an institutional-grade, zero-dependency browser vector design engine and spatial UI canvas simulator. Engineered with infinite pan-and-zoom viewport mathematics, reactive auto-layout hierarchy, autonomous simulated multiplayer presence, and an instant DevMode compiler (CSS3, Tailwind CSS, React JSX).

## 🚀 Key Architectural Pillars
- **Infinite 2D Spatial Canvas**: Sub-pixel pan/zoom transformation matrix centered on cursor coordinate frames.
- **Simulated Real-Time Multiplayer Presence**: Autonomous collaborator cursor agents (Sarah [UI Designer], Kenji [Design Lead], Alex [Frontend Lead]) with dynamic waypoints and contextual review bubbles.
- **Reactive AST Auto-Layout**: Interactive flex engine (direction, padding, gap, alignment) with live viewport updates.
- **Instant DevMode Compiler**: Real-time extraction of native CSS, Tailwind classes, and React JSX for any selected layer.
- **Interactive Device Mockup Presentation**: Fullscreen presentation mode simulating interactive touch prototypes at 60 FPS.
- **Export Pipeline**: Direct vector SVG and raster snapshot serialization.
